Experiment 1 - Dress Service

One-line run command (PowerShell):
cd 'v:\basic-api-cls\springboot\springboot\exp1\dress-service'; .\mvnw.cmd spring-boot:run

Endpoints (use http):
- GET http://localhost:8080/api/info
- GET http://localhost:8080/api/dresses
- GET http://localhost:8080/api/dresses/1
- POST http://localhost:8080/api/dresses
  - Header: Content-Type: application/json
  - Body (JSON):
    {
      "id": 3,
      "name": "Denim Casual Dress",
      "category": "Casual",
      "price": 1599,
      "size": "M"
    }
- PUT http://localhost:8080/api/dresses/1
  - Header: Content-Type: application/json
  - Body (JSON):
    {
      "id": 1,
      "name": "Premium Floral Summer Dress",
      "category": "Casual",
      "price": 1499,
      "size": "L"
    }
- DELETE http://localhost:8080/api/dresses/3

Experiment 5 - Standalone Order Service

One-line run command (PowerShell):
cd 'v:\basic-api-cls\springboot\springboot\exp5\order-service'; .\mvnw.cmd spring-boot:run

Endpoints (http://localhost:8081):
- GET http://localhost:8081/api/orders
- GET http://localhost:8081/api/orders/1
- POST http://localhost:8081/api/orders
  - Header: Content-Type: application/json
  - Body (JSON):
    {
      "id": 3,
      "customerId": 1,
      "dressName": "Denim Casual Dress",
      "amount": 1599,
      "status": "Confirmed"
    }
- PUT http://localhost:8081/api/orders/1
  - Header: Content-Type: application/json
  - Body (JSON): similar to POST
- DELETE http://localhost:8081/api/orders/3


Notes:
- Use one terminal per running service (multiple services cannot share a single terminal process).
- Use the integrated VS Code Terminal (Ctrl+`) to paste commands. If you paste multiple lines into some VS Code quick-run fields, it may reject them; paste into the Terminal prompt.
- All URLs use http and localhost since these services run locally without TLS.
